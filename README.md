# 白山，一日秋行

2026 年 10 月 3 日，从波士顿出发的白山赏叶一日行程。

包含路线与时间表、Lincoln 午餐备选、Tesla 补电安排、目的地摄影建议和动物观察笔记。页面适配电脑、手机与横屏触控浏览器。

## 在线访问

https://schrodog2.github.io/white-mountains/

可在 Tesla 车载浏览器输入网址后收藏；无需登录 GitHub。

## 发布

使用 GitHub Pages，从 `main` 分支根目录发布。入口为 `index.html`，无需构建依赖。

## 更新

替换 `index.html` 并提交至 `main`，GitHub Pages 会自动重新发布。

## 图片与资料

实景照片已嵌入 HTML；作者、原始来源与许可见网页页末。餐厅菜单、地图和其他资料链接需要联网访问。

本行程的日期、叶色、营业时间与充电站信息对应制作时的计划；出行时以当地最新信息为准。
